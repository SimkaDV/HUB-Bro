# Настройки — документация

Раздел кабинета, где хранятся данные подключений к внешним сервисам и настройки принтера. Позже здесь же появятся
вход и доступы.

**Как пользоваться документом:** перед работой с настройками (`web/src/features/settings/`) читай его; после
изменения (поля, логика, тексты) обнови нужные разделы и журнал внизу в том же коммите.

---

## 1. Меню

Порядок разделов слева: **Пульт → Комплектация → Склад → Заказы → Настройки**. Порядок задаёт список в
`web/src/app/routes.tsx`. Открывается по умолчанию пока Склад (`defaultPath`).

## 2. Экран

Шапка «Настройки», под ней пояснение про хранение в браузере и четыре **раскрывающихся раздела**:
Авито, Telegram-бот, Принтер, Авторизация. В шапке раздела — название, одна строка «зачем», статус и стрелка;
клик раскрывает или сворачивает. Открытыми могут быть несколько сразу; при заходе на страницу все свёрнуты.

## 3. Подключения Авито и Telegram

Поля с кнопками «Сохранить» / «Отменить» / «Стереть».

### Авито

| Поле | Ключ | Обязательное | Что это |
|---|---|---|---|
| Client ID | `clientId` | да | Ключ API из профиля Авито (Для профессионалов → API) |
| Client secret | `clientSecret` | да, секрет | Секрет к Client ID |
| Номер профиля | `userId` | да | Номер аккаунта продавца — нужен для запросов сделок |

Зачем: по ним забираем оплаченные сделки и их статусы (см. [ORDERS.md](ORDERS.md), [ROADMAP.md](ROADMAP.md)).

### Telegram-бот

| Поле | Ключ | Обязательное | Что это |
|---|---|---|---|
| Токен нашего бота | `botToken` | да, секрет | Выдаёт @BotFather |
| Бот Гришки | `sizeBot` | да | @username или ID бота, чьи сообщения принимаем как размеры |
| Чат обмена | `chatId` | нет | ID группы, если обмен ботов идёт через группу |

Зачем: размеры от бота Гришки и команда «спроси размер» (ROADMAP, «Связь с ботом Гришки»). Схема «бот читает
бота» ещё не проверена — поля могут поменяться.

## 4. Принтер

Xprinter XP-365B: термопечать без ленты, 203 dpi (8 точек на мм), ширина бирки 20–80 мм, до 5 дюймов в секунду,
USB, язык команд TSPL. Наша бирка — 80×50 мм (ROADMAP). Код — `shared/printer/`: им пользуются и настройки, и
(этап 2) пульт.

### Как печатаем — WebUSB (решено 16.11.2026)

Chrome сам говорит с принтером по USB: **без драйвера, без программы на компьютере, без окна печати.**

1. Один раз в «Настройки → Принтер» жмём **«Подключить принтер»** — Chrome показывает список USB-устройств,
   выбираем Xprinter. Без клика человека браузер к USB не пускает. Выбор Chrome запоминает, у нас в
   localStorage — какой это принтер (`hubbro.printer.device.v1`: коды производителя и модели, серийный номер, имя).
2. Бирку рисуем сами на холсте в точках принтера (80×50 мм = 640×400) и переводим в чёрно-белое (раздел
   «Бирка»).
3. Картинку отправляем командой TSPL `BITMAP`. Задание: `SIZE`, `GAP`, `DENSITY`, `SPEED`, `DIRECTION`,
   `REFERENCE` один раз, дальше на каждую бирку `CLS → BITMAP → PRINT 1,1`. В `BITMAP` бит 1 — белая точка, 0 —
   чёрная.
4. Байты уходят в bulk OUT канал устройства (лучше у интерфейса класса «принтер», 7) кусками по 16 КБ. Задания идут
   по очереди, чтобы партии не перемешались.

**Ограничения:**
- Только Chrome или Edge (Safari не умеет WebUSB), сайт по `https` или `localhost`.
- Принтер **не добавлять в системные принтеры Mac** и не ставить драйвер — иначе macOS может перехватить его и
  Chrome получит «нет доступа».
- Принтер держит одна вкладка: в другой вкладке будет «нет доступа».
- WebUSB подтверждает только, что принтер **принял данные.** Кончилась лента или замяло — видно глазами, для этого
  на пульте есть «Бирка не напечаталась».
- На Windows понадобится один раз поставить WinUSB через Zadig.

**Запасной вариант,** если WebUSB не заведётся: драйвер Xprinter + окно печати браузера, бирка — страница 80×50.
**Print Agent** (программа на компьютере) — только если понадобится печать по сети (порт 9100), с сервера без
открытого пульта или из Safari. Пока не делаем.

### Статус

| Состояние | Бейдж раздела | Когда |
|---|---|---|
| `unsupported` | Нужен Chrome (красный) | В браузере нет WebUSB |
| `notPaired` | Не подключён (серый) | Принтер ещё не выбирали |
| `notFound` | Не найден (жёлтый) | Выбран, но сейчас не воткнут или выключен. Воткнули — подхватится сам |
| `ready` | Подключён (зелёный) | Выбран и на связи |

### Бирка

Раскладка нарисована под 80×50 мм и масштабируется под другие размеры:

```
┌──────────────────────────────────────┐
│ [ЛОГО]                    ┌────────┐ │
│                           │   QR   │ │
│ Джинсы Трубы              │        │ │
│ ██ 31M ██                 └────────┘ │
│ № 4 812 338 871                      │
└──────────────────────────────────────┘
```

- Логотип `public/logo.png`, товар (модель склада), размер крупно белым на чёрной плашке, номер заказа Авито.
- **QR** — номер заказа Авито как есть (без пробелов), коррекция ошибок M, каждый модуль — целое число точек.
  Библиотека `qrcode-generator`.
- Текст шрифтом Onest, с кириллицей: встроенные шрифты принтера её не знают, поэтому бирка уходит картинкой.
- Чёрно-белое по порогу яркости 140: принтер не умеет серый.
- **Превью = печать:** в настройках показываем тот же холст, что уходит принтеру (пример заказа).

### Поля

| Поле | Ключ | По умолчанию | Границы |
|---|---|---|---|
| Ширина бирки | `labelWidth` | 80 мм | 20–80 |
| Высота бирки | `labelHeight` | 50 мм | 10–200 |
| Зазор между бирками | `gap` | 2 мм | 0–10 |
| Плотность | `density` | 8 | 0–15 |
| Скорость | `speed` | 4 дюйм/с | 2–5 |
| Перевернуть бирку | `flip` | нет | `DIRECTION 0` вместо `1` |

Хранятся в localStorage, ключ `hubbro.printer.v1`. «Сохранить» неактивно, пока число вне границ (поле краснеет).
«По умолчанию» (с подтверждением) возвращает значения из таблицы.

### Пробная печать

Одна бирка-пример с **текущими значениями формы, даже несохранёнными** — чтобы подобрать плотность и зазор, не
сохраняя каждый раз. Активна, когда принтер «Подключён» и числа в границах. Под формой — «Отправлено в 12:30» или
понятная ошибка (нет доступа, связь прервалась, принтер не найден).

### Проверить на живом принтере

1. Видит ли Chrome принтер и отдаёт ли его macOS без драйвера.
2. Понимает ли наш экземпляр TSPL сразу (у некоторых Xprinter режим «чеки / бирки» переключается кнопкой).
3. Ширина печати: если у принтера печатная область уже 80 мм (например, 72 мм), край бирки с QR обрежется —
   тогда сдвинем раскладку.
4. Направление (`flip`), плотность, зазор, читается ли QR телефоном, как выглядит логотип.
5. Коды производителя и модели — поставить фильтр в окошко выбора, чтобы показывать только принтер.

## 5. Авторизация

Заглушка: раздел со статусом «Позже» и текстом, что кабинет пока открыт всем по ссылке и здесь появятся вход и
доступы. Никакой логики нет.

## 6. Правила

1. Секреты на экране скрыты точками, пока не нажали «Показать».
2. «Стереть» — только с подтверждением.
3. Пробелы по краям при сохранении обрезаются, пустые поля не сохраняются.
4. Статус карточки: «Не подключено» — ничего не внесено; «Заполнено не всё» — не хватает обязательного поля;
   «Данные внесены» — все обязательные поля есть. **Рабочие ли ключи, не проверяем** — без сервера нельзя.

## 7. Хранение

Пока бэкенда нет, значения лежат в localStorage этого браузера, ключ `hubbro.connections.v1`
(`avito`, `telegram`), никуда не отправляются. Настройки принтера — отдельно, `hubbro.printer.v1`; выбранный
принтер — `hubbro.printer.device.v1`. **До живого запуска** данные переезжают на сервер: секреты не должны жить в браузере, а запросы к
Авито и Telegram идут с сервера. Тогда же появится кнопка «Проверить подключение».
