# Склад

Решения по вкладке «Склад», согласованы 14.11.2026. Код: `web/src/features/stock/` (пока на тестовых данных `mockData.ts`).

## Структура данных

- **Категория** — Джинсы, Куртки. Обязательна у каждой модели.
- **Модель** — Джинсы Клёш, Джинсы Трубы, Куртка Дутая. Цветов пока нет: если появятся, это отдельная модель («Клёш чёрные»).
- **Размер** — просто подпись: «31M», «30S», «XL». На талию и длину не разбираем, расширим позже.
- **Партия** — закупка одной модели в один день: название, дата, откуда, одна закупочная цена на всю партию.
  Одна партия = одна модель.
- **Джинса (единица)** — модель + размер + партия + статус.
  На полке джинсы безликие: все 31M одной кучей, учитываются как количество по партиям.
  Уникальной джинса становится, когда к ней привязывается заказ: в резерв берётся единица из самой старой партии.
  Бирка на саму джинсу не клеится, только этикетка на упаковку при отправке.

## Статусы

```
На складе → В резерве → Отправлена → Доставлена (в ПВЗ) → Продана
Возврат едет → Возврат на складе (нужно разобрать) → На складе
```

Проданные в интерфейсе скрыты, «показать историю» — потом.

## Экран

**Сетка плиток (бенто).** Одна общая сетка без деления на категории; фильтр `Все · Джинсы · Куртки`
добавим, когда моделей станет больше ~10. Плитки сортируются по срочности: сверху модель, где больше всего горит.

**Плитка:** название и до двух рядов чипов размеров (по 3 в ряд). Порядок чипов: нет → мало → норм → много.
Не влезает — последний чип «+N».

**Чип размера:** `31M 5 +1`.
- Число — только «На складе».
- Цвет числа: 0 серый зачёркнутый, ≤ 5 красный, 6–10 жёлтый, > 10 зелёный.
- «+N» мелко — возвраты, которые едут к нам.

**Раскрытая модель:** шапка (название + все чипы), под ней размеры по порядку (30S, 30M, 31S…).
Размер раскрывается:

```
31M  5 +1
 ├─ На складе   · «Клёш 02.11» · 1 450 ₽ · ×3     ← одна строка на партию
 ├─ На складе   · «Клёш 12.11» · 1 400 ₽ · ×2
 ├─ В резерве   · заказ №1234                     ← строка на каждую джинсу с заказом
 ├─ Возврат на складе · заказ №1198 · разобрать
 └─ Показать всё ▾
      ├─ Отправлена   · заказ №1229
      ├─ Доставлена   · заказ №1221
      └─ Возврат едет · заказ №1210
```

Строка с заказом раскрывается: товар, размер, статус, заказ и дата, ПВЗ, партия и откуда, закупочная цена.
