# HUB BRO

Внутренний кабинет для продажи джинсов через Авито: оплаченная сделка + размер из чата → склад → очередь печати → бирка на Xprinter 365B.

## Проект перезапущен с нуля (2026-11-14)

Всё, что было до коммита `b3a59ef`, — старая версия, которую снесли: старый бэкенд и кабинет, старые роадмапы, решения про печать транспортных этикеток Авито, ветки и сессии до этой даты. **Не опирайся на них** ни в логике приложения, ни в дизайне, ни в архитектуре.

Источники правды — только эти файлы:

- [docs/ROADMAP.md](docs/ROADMAP.md) — как проходит заказ, решения, риски, открытые вопросы, этапы
- [docs/DESIGN.md](docs/DESIGN.md) — палитра, статусы, шрифт Onest, форма элементов, логотип
- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) — структура `web/` и правила слоёв
- [docs/WAREHOUSE.md](docs/WAREHOUSE.md) — склад: модели, партии, статусы джинс, экран

Если решение меняется — правь соответствующий документ в том же коммите.

## Работа

- Общение на русском, разговорно.
- Кабинет: `web/` (Vite + React + TypeScript). Запуск — конфигурация `web` в `.claude/launch.json`.
- Проверка: `npx tsc -b` в `web/`.
- Интерфейс делаем сразу на сайте, без отдельных макетов: не понравится — откатим.
